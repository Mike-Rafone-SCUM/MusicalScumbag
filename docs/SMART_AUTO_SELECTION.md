# Smart auto-select

Choose an arrangement, then press **Smart auto-select**. For vocal-heavy songs, begin with **Custom → Vocal · Foundation / 2** or **Vocal · Warm ballad / 3**. The selector prefers the main singer, chooses useful lower support and can retain an instrumental part for a real gap in the lead.

If the vocal has a generic track name, check that track manually and choose it in **Lead track (suite)** before pressing Smart auto-select. Auto uses names and musical evidence; it cannot prove that an unnamed MIDI instrument represents the sung tune.

Hover a track to see why it was selected or excluded. The advisory panel explains the complete source set. Exact and octave-doubled parts are compared against the whole selected set, and percussion/FX tracks are excluded. Changing arrangements does not silently change the checkboxes; click Smart auto-select again when you want a new recommendation.

Source tracks are alternatives for the arranger, not simultaneous key presses. Fuller recipes receive more source layers, while Maximum chord notes and physical timing still limit playback. Saved manual selections, including no tracks selected, remain intact on reload. No MIDI file is rewritten.

Prepare and audition the same passage under supervision. These changes have automated regression coverage; current-build SCUM musical quality and optional Basic Pitch inference have not been revalidated.
